AI Systems I Build

Three custom agents and fourteen skills, built in Claude Code between September 4 and September 28, 2026. I did not automate tasks — I identified recurring roles and encoded the judgment that runs them. Each agent is constrained a different way, and the constraint is chosen to fit how that particular job fails.

application-coach
Built Sep 27, 2026 · Constrained by tools
Screens a job posting against eight hard filters — term and format, graduation date, GPA floor, class standing, citizenship, location and work pattern, preferred majors, real deadline — before I spend time on it. Then it names who at the company should hear from me, and what artifact would confirm the application actually landed.
The design decisionIts permissions are read-only: no write access to my tracker, letters, or logs. Building a system so it cannot misbehave beats asking it to behave — the same distinction as a process control versus a written procedure. Every filter was added after a real posting cost me something.
analytics-study-partner
Built Sep 7, 2026 · Constrained by sequence
Quizzes me on FinTech and analytics coursework and refuses to hand over answers. The order is fixed: ask what I already think a concept means, name precisely what I had right and wrong, then make me say it back before moving on.
The design decisionIt grounds every abstract concept in the supply chain work I actually did before defining it — forecast exceptions as variance and outliers, the A- and B-tier supplier mix as distribution and skew, 9,245 SKUs against one brand's 40 as sample size. When my job intuition is right it names the term; when it is wrong it says so, because a wrong intuition carried from work is worse than none.
think-with-me
Built Sep 6, 2026 · Constrained by prohibition
A thinking partner for real decisions that asks one question at a time and waits. Four moves: reflect back what it heard, probe the load-bearing assumption, ask what a named person who disagrees would say, and walk the version where the decision failed.
The design decisionIt is forbidden from offering options, frameworks, or recommendations — not as a preamble, not as a closing summary. I wrote my own failure mode into the spec so it resists me: my reflex is to ask for output and feel productive. Most people build an agent that serves their instincts; this one refuses them, because the instinct is the problem.
Verified Result · September 27, 2026

application-coach screened eight postings in a single session. Seven cleared and got tailored cover letters. One was rejected: a requisition titled "Financial Analyst, Supply Chain" that was actually a full-time hire requiring one to three years of experience — caught before a slot or a letter was spent on it. The same session flagged a U.S.-citizen-only gate on a defense posting, a 3.0 GPA floor against my 3.00 cumulative, and a five-day close window on a fourth. None of those four were visible from the job title. The screen runs in the agent's own context window, so none of that reading crowds the conversation it reports into.

The fourteen skills are the layer below: a skill scales a task, one repeatable procedure run inside the main conversation, where an agent scales a role with its own tools and context. Five of them chain into one job-search pipeline — screen a posting, draft the letter, log the activity, close the week, report outward. Four govern writing, three handle analysis and prep, one manages how context gets handed to a model, and one keeps the catalog of all of it current.

Five rules recur across all of them: screen before you build, keep sources attached to claims, let framing change but never the facts, refuse rather than fake, and give every tool an explicit list of what it must not do. They carry dated revision notes explaining why a rule changed, which is the difference between a prompt library and a maintained system — the same discipline as an SOP that cites the incident behind the revision.

Why this is on a career site rather than in a hobby folder: a Coinbase Strategic Finance internship posting I applied to on September 27, 2026 listed “proficiency with at least one agentic coding harness” as a required qualification. That is a hiring filter in a finance role at a public company. These run inside Claude Code on my own machine — personal tooling, not deployed software.
